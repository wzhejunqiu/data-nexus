# v0.2 — Manual Test Checklist

> 发布 v0.2.0 前在本机走查。详见 [phase-v0.2-enhancements.md](./phase-v0.2-enhancements.md) 与设计文档 [API.md](../design/API.md)、[UI_UX.md](../design/UI_UX.md)。

## 行内编辑与批量提交

- [ ] 双击单元格进入编辑态，Esc 取消单格编辑
- [ ] 修改多个单元格后，待提交栏显示变更数量
- [ ] 已改单元格视觉高亮（与未改区分）
- [ ] 点击「提交」弹出确认 Modal，列出变更摘要
- [ ] 提交成功刷新当前页，Toast 提示成功
- [ ] 提交失败整批回滚，无部分写入；错误信息可读
- [ ] 点击「放弃」清除所有 pending 编辑
- [ ] 只读连接下编辑被拦截（`READ_ONLY`）
- [ ] 超过 200 条变更时前端阻止提交并提示
- [ ] BLOB 列不可编辑（或明确禁用态）
- [ ] NULL ↔ 值 互转正确

## CSV 导出

- [ ] 数据 Tab 工具栏「导出 CSV」可用
- [ ] 导出范围：当前页 / 全表 均可选
- [ ] 格式选项：分隔符、引号、是否表头、NULL 表示、编码（UTF-8 / BOM）
- [ ] `SaveFile` 对话框默认文件名 `{table}.csv`
- [ ] 取消保存对话框不报错（`DIALOG_CANCELLED` 静默处理）
- [ ] 导出文件可用 Excel / Numbers 正常打开
- [ ] SQL 结果区「导出 CSV」导出当前结果集
- [ ] 大表全表导出进度提示（或异步 Toast）

## CSV 导入

- [ ] `OpenCSVFile` 选择 CSV 文件
- [ ] 导入预览显示列名与前若干行
- [ ] 新建表：输入表名，推断列类型，执行 CREATE + INSERT
- [ ] 已有表 append：列映射正确，追加行
- [ ] 已有表 update：主键匹配 UPSERT；无主键时提示不可用
- [ ] 格式选项与导出共用（分隔符、引号等）
- [ ] 导入完成刷新 Schema 树与数据 Tab
- [ ] 只读连接下导入被拦截
- [ ]  malformed CSV 展示解析错误

## SQL 编辑器增强

- [ ] 输入 `SELECT * FROM u` 时出现表名补全
- [ ] 输入列名时出现当前表列补全
- [ ] SQL 格式化按钮可用
- [ ] EXPLAIN 查询展示计划树（或表格化计划）

## 设置页

- [ ] View → Settings 或等效入口打开设置面板
- [ ] 修改日志级别后生效（无需重启）
- [ ] 修改日志输出路径 / 模式 / 轮转参数后写入 `~/.data-nexus/config.yaml`（需重启生效）
- [ ] 语言偏好切换正常（若 v0.2 纳入）
- [ ] 无效配置值 inline 校验

## 连接与文件（v0.2 新增项）

- [ ] 双击 `.db` 文件关联打开应用（目标平台安装器）
- [ ] CLI `./data-nexus /path/to/app.db` 打开连接

## 回归（v0.1 核心路径）

- [ ] 多连接打开/关闭/持久化仍正常
- [ ] 分页、排序、SQL 执行、写操作确认仍正常
- [ ] 主题 / i18n 仍正常
