# Data Nexus — 产品需求文档 (PRD)

> 版本: v0.3 · 状态: 草案 · 最后更新: 2026-06-07

## 1. 产品概述

### 1.1 背景

开发者在本地调试、数据分析、运维排查时，经常需要快速查看和操作 SQLite 数据库。现有工具（DBeaver、TablePlus、DB Browser for SQLite）功能强大但较重，或 UI 老旧。

**Data Nexus** 是一款面向开发者的轻量级 **桌面数据库管理应用**（Wails + Go + React），提供连接、浏览、查询能力。MVP 仅支持 SQLite；架构从第一天起为多数据库连接预留扩展点。

### 1.2 产品愿景

成为开发者本地/内网环境下「打开即用、足够轻量、可扩展」的数据库工作台。

**一句话定位：** 面向开发者的轻量 **桌面** 数据库工作台 — Wails 单二进制、原生文件对话框、SQLite 开箱即用，架构面向多库扩展。

**核心卖点：**
1. **Wails 桌面** — 系统 WebView，~15MB 级体积，秒开，非 Electron/Java
2. **原生体验** — 系统文件对话框、菜单栏、双击 `.db` 打开（v0.2）
3. **多库演进路径** — 非 SQLite 玩具，v1.x 可扩展 PostgreSQL/MySQL
4. **探索式分析 Lite** — 列画像、Filter→SQL（v0.3）
5. **现代开发者 UX** — Monaco、暗色主题、键盘流、TypeScript 前端
6. **Go 统一技术栈** — 后端/桌面壳/DB 驱动同一语言，易维护

详见 [竞品调研与差异化策略](./COMPETITIVE_ANALYSIS.md)。

### 1.3 目标用户

| 用户类型 | 典型场景 | 核心诉求 |
|----------|----------|----------|
| 后端开发者 | 调试应用内嵌 SQLite、查看 ORM 迁移结果 | 快速打开 `.db` 文件，浏览表结构和数据 |
| 数据/分析工程师 | 探索本地数据集 | 执行 SQL、分页查看结果 |
| 全栈开发者 | 前后端联调 | 轻量启动、无需重型客户端 |

### 1.4 非目标（MVP 不做）

- 多用户权限与 RBAC
- 云端托管 / SaaS 部署
- 数据可视化图表、BI 报表
- 在线协同编辑
- 生产环境远程数据库直连（MySQL/PostgreSQL 等，留待 v1.x）
- 数据库结构迁移 / DDL 可视化设计器
- 完整 BI 图表 / ER 图（v1.x 再评估）
- AI SQL 助手（市场拥挤，与本地优先定位冲突）
- SQLCipher 加密管理（ niche，后续社区插件）

## 2. MVP 范围

### 2.1 功能清单

| 优先级 | 功能 | 描述 |
|--------|------|------|
| P0 | 连接 SQLite 文件 | 系统文件对话框 + 路径输入；支持 `.db` / `.sqlite` / `.sqlite3` |
| P0 | 连接状态管理 | 显示连接状态；断开连接；同一时刻仅一个活跃连接 |
| P0 | Schema 浏览 | 列出所有表、视图；展示列名、类型、主键、NOT NULL 等 |
| P0 | 表数据浏览 | 分页读取表数据；支持排序（单列 ASC/DESC） |
| P0 | SQL 编辑器 | 输入并执行 SELECT / 只读查询；展示结果集与执行耗时 |
| P0 | 写操作 SQL | 支持 INSERT / UPDATE / DELETE（带确认提示） |
| P0 | 只读连接模式 | 连接时可勾选，拒绝写操作（借鉴 sqlite-web） |
| P0 | 原生打开文件 | Wails 文件对话框 + 菜单 File → Open |
| P1 | 索引信息 | 在表详情中展示索引列表 |
| P1 | 查询历史 | 当前会话内保留最近 N 条 SQL 记录 |
| P1 | 深色/浅色主题 | 跟随系统或手动切换 |
| P1 | PRAGMA 快捷入口 | 常用 PRAGMA 一键查看（table_info、foreign_keys 等） |
| P1 | 结果集 CSV 复制 | 查询结果一键复制为 CSV（借鉴 Beekeeper） |
| P1 | 复制表名/列名 | 侧边栏和 Schema 表右键或按钮复制 |
| P2 | 单元格 NULL 高亮 | 结果集中 NULL 值视觉区分 |
| P2 | 行数统计 | 表总行数（大表可异步或近似） |

### 2.2 MVP 约束

- **单连接**: 同时仅维护一个 SQLite 连接实例
- **桌面应用**: Wails 原生窗口，非浏览器 Tab；数据与逻辑均在本地进程
- **文件访问**: 系统文件对话框或 CLI 参数 `--db`；Go 后端直接读本地文件系统
- **无持久化配置**: MVP 不保存连接历史到磁盘（会话级内存即可）

### 2.3 成功指标

| 指标 | 目标 |
|------|------|
| 冷启动到窗口可见 | < 1 秒 |
| 10 万行表首页加载 | < 500ms（LIMIT 分页） |
| 简单 SELECT 查询响应 | < 200ms（1 万行以内） |
| 核心流程可用性 | 连接 → 浏览表 → 执行 SQL 全流程无阻断 |

## 3. 用户故事

### Epic 1: 连接管理

```
作为开发者，
我希望通过文件路径连接本地 SQLite 数据库，
以便快速开始查看数据。
```

**验收标准:**
- [ ] 点击「打开数据库」弹出系统文件对话框，选择有效文件后连接成功
- [ ] 输入有效路径后，连接成功并显示数据库文件名
- [ ] 无效路径 / 非 SQLite 文件时，显示明确错误信息
- [ ] 文件被其他进程锁定时，提示「数据库被锁定」
- [ ] 可主动断开连接，断开后 Schema 面板清空

### Epic 2: Schema 探索

```
作为开发者，
我希望在侧边栏看到所有表和视图，
以便了解数据库结构。
```

**验收标准:**
- [ ] 侧边栏按字母序列出 `table` 与 `view`
- [ ] 点击表名，右侧展示列定义（名称、类型、PK、nullable、default）
- [ ] 点击「查看数据」，进入该表的数据浏览视图

### Epic 3: 数据浏览

```
作为开发者，
我希望分页浏览表数据并排序，
以便检查记录内容而无需写 SQL。
```

**验收标准:**
- [ ] 默认每页 50 行，可选 25 / 50 / 100 / 200
- [ ] 支持点击列头排序（升序/降序切换）
- [ ] 显示当前页码与总页数（或「共 N 行」）
- [ ] BLOB 类型显示为 `[BLOB N bytes]`，不渲染二进制

### Epic 4: SQL 工作台

```
作为开发者，
我希望在 SQL 编辑器中执行查询并看到结果，
以便灵活探索数据。
```

**验收标准:**
- [ ] 支持多行 SQL 输入，Monaco 或等价编辑器（语法高亮 optional P1）
- [ ] 执行 SELECT 返回表格化结果集 + 行数 + 耗时
- [ ] 执行写操作前弹出确认对话框，展示影响行数
- [ ] SQL 语法错误时，展示数据库返回的错误信息
- [ ] 支持 `Cmd/Ctrl + Enter` 快捷键执行

## 5. 竞品参考（摘要）

| 产品 | 优势 | Data Nexus 差异化 |
|------|------|---------------------|
| DB Browser for SQLite | SQLite 功能最全、Spreadsheet 编辑 | 现代 Web UI、单二进制、API 原生、多库路线 |
| Beekeeper Studio | 精美 UI、自动补全、多 Tab | 更轻量、开源全栈、可嵌入、无 Electron |
| TablePlus | Native 性能、极简 | 开源、Web 可集成、API-First |
| DBeaver | 100+ 数据库、ER 图 | 聚焦开发者日常、秒开、不做 heavyweight |
| Datasette | Filter/Facet/FTS、JSON API | 更强 SQL 工作台 + 同样 API 理念 + 多库扩展 |
| Tabulita | Go 单二进制、JSON API | **Wails 桌面 + 现代 UI**、原生对话框、多库路线 |
| sqlite-web | 极简 Python Web、导入导出 | Go 部署更简单、TypeScript 前端、架构可扩展 |
| DuckDB UI | 列画像、Notebook、Instant SQL | 借鉴探索 UX，但聚焦 SQLite + 多库平台 |
| Sqlime | 零服务端 WASM | 原生桌面 + 本地文件对话框 + 多库路线 |

## 6. 风险与假设

| 类型 | 描述 | 缓解措施 |
|------|------|----------|
| 假设 | 用户在本机运行，可访问文件系统 | MVP 不做远程文件；后续可考虑文件上传 |
| 风险 | SQLite 写操作误删数据 | 写操作二次确认 + 只读连接模式（P0） |
| 风险 | 大表/大结果集内存溢出 | 强制分页 + 结果集行数上限（如 10,000） |
| 风险 | 多数据库抽象过度设计 | MVP 仅实现 SQLite Driver，接口预留但不提前实现 |

## 7. 术语表

| 术语 | 定义 |
|------|------|
| Connection | 一次到数据库实例的活跃会话 |
| Schema | 数据库内表、视图、索引等结构元信息 |
| Driver | 后端适配特定数据库类型的连接与元数据查询模块 |
| Workspace | 前端整体布局区域（侧边栏 + 主内容区） |

## 8. 开放问题

- [x] MVP 是否需要「只读连接」模式？→ **连接时可勾选，默认读写**
- [x] 文件选择方式？→ **MVP 原生文件对话框（Wails）+ 可选路径输入**
