# Data Nexus — 产品需求文档 (PRD)

> 版本: v0.3 · 状态: 草案 · 最后更新: 2026-06-07

## 1. 产品概述

### 1.1 背景

开发者在本地调试、数据分析、运维排查时，经常需要快速查看和操作 SQLite 数据库。现有工具（DBeaver、TablePlus、DB Browser for SQLite）功能强大但较重，或 UI 老旧。

**Data Nexus** 是一款面向开发者的轻量级 **桌面数据库管理应用**（Wails + Go + React），提供连接、浏览、查询能力。MVP 仅支持 SQLite；架构从第一天起为多数据库连接预留扩展点。

### 1.2 产品愿景

成为开发者本地/内网环境下「打开即用、足够轻量、可扩展」的数据库工作台。

**一句话定位：** 类 Navicat 的轻量桌面数据库工作台 — 启动即主界面、多 SQLite 同时打开、Wails 单二进制。

**核心卖点：**
1. **Wails 桌面** — 系统 WebView，~15MB 级体积，秒开
2. **多连接并存** — 同时打开多个 `.db`，侧边栏连接树（MVP）
3. **连接持久化** — 保存连接配置，启动即见列表，一点即开
4. **多库演进** — v1.x 扩展 PostgreSQL/MySQL
5. **探索式分析 Lite** — 列画像、Filter→SQL（v0.3）
6. **现代 UX** — Monaco、i18n、暗色主题

详见 [竞品调研与差异化策略](./COMPETITIVE_ANALYSIS.md)。

### 1.3 目标用户

| 用户类型 | 典型场景 | 核心诉求 |
|----------|----------|----------|
| 后端开发者 | 调试应用内嵌 SQLite、查看 ORM 迁移结果 | 快速打开 `.db` 文件，浏览表结构和数据 |
| 数据/分析工程师 | 探索本地数据集 | 执行 SQL、分页查看结果 |
| 全栈开发者 | 前后端联调 | 轻量启动、无需重型客户端 |

### 1.4 非目标（MVP 不做）

- 多用户权限与 RBAC
- 云端托管 / SaaS 部署
- 数据可视化图表、BI 报表
- 在线协同编辑
- 生产环境远程数据库直连（MySQL/PostgreSQL 等，留待 v1.x）
- 数据库结构迁移 / DDL 可视化设计器
- 完整 BI 图表 / ER 图（v1.x 再评估）
- AI SQL 助手（市场拥挤，与本地优先定位冲突）
- SQLCipher 加密管理（ niche，后续社区插件）

## 2. MVP 范围

### 2.1 功能清单

| 优先级 | 功能 | 描述 |
|--------|------|------|
| P0 | **启动即主界面** | 无 Welcome；直接进入连接列表 + 工作区 |
| P0 | **多连接并存** | 可同时打开多个 SQLite；各连接独立 Schema / SQL 上下文 |
| P0 | 新建 SQLite 连接 | 文件对话框 + 表单；保存到连接列表 |
| P0 | 打开 / 关闭连接 | 从列表打开数据库；关闭释放会话，配置仍保留 |
| P0 | **连接信息持久化** | `catalog.db`（v0.5+）；重启后列表仍在；**不自动迁移**旧版 `connections.json` |
| P0 | Schema 树 | 每个已打开连接下展开 tables / views |
| P0 | 表数据浏览 | 分页、排序（绑定当前连接 + 表） |
| P0 | SQL 编辑器 | 绑定当前连接；执行 SELECT / 写操作（含确认） |
| P0 | 只读连接模式 | 新建/编辑连接时可设只读 |
| P1 | 连接别名 | 重命名显示名 |
| P1 | 启动恢复已打开连接 | 可选：退出时记录的打开项，下次启动自动 Open |
| P1 | 索引信息 | 在表详情中展示索引列表 |
| P1 | 查询历史 | 当前会话内保留最近 N 条 SQL 记录 |
| P1 | 深色/浅色主题 | 跟随系统或手动切换 |
| P1 | PRAGMA 快捷入口 | 常用 PRAGMA 一键查看（table_info、foreign_keys 等） |
| P1 | 结果集 CSV 复制 | 查询结果一键复制为 CSV（借鉴 Beekeeper） |
| P1 | 复制表名/列名 | 侧边栏和 Schema 表右键或按钮复制 |
| P2 | 单元格 NULL 高亮 | 结果集中 NULL 值视觉区分 |
| P2 | 行数统计 | 表总行数（大表可异步或近似） |

### 2.2 MVP 约束

- **多连接**: 可同时打开多个 SQLite；每条连接独立 Driver 会话
- **启动体验**: 直接进入主界面；左侧为**全部已保存连接**（含已打开 / 未打开状态）
- **桌面应用**: Wails 原生窗口
- **连接持久化**: `~/.data-nexus/catalog.db`（v0.5+；不自动导入旧版 `connections.json`）
- **P1 全做**: MVP v0.1.0 含全部 P0 + P1
- **i18n**: zh-CN + en
- **首发平台**: macOS / Windows / Linux

交互细节见 [CONNECTION_UX.md](../design/CONNECTION_UX.md)。

### 2.3 成功指标

| 指标 | 目标 |
|------|------|
| 冷启动到窗口可见 | < 1 秒 |
| 10 万行表首页加载 | < 500ms（LIMIT 分页） |
| 简单 SELECT 查询响应 | < 200ms（1 万行以内） |
| 核心流程可用性 | 连接 → 浏览表 → 执行 SQL 全流程无阻断 |

## 3. 用户故事

### Epic 1: 连接管理（Navicat 模式）

```
作为开发者，
我希望启动即看到所有连接，并可同时打开多个 SQLite 文件，
以便像 Navicat 一样在多库之间切换工作。
```

**验收标准:**
- [x] 启动后直接进入主界面，无 Welcome 门页
- [x] 左侧列表展示全部已保存连接（名称、路径、已打开/未打开状态）
- [x] 「新建连接」→ 选文件 → 出现在列表，可立即打开
- [x] 点击「打开」→ 连接成功，该连接下展开 Schema 树（● 状态）
- [x] 可同时打开 ≥2 个连接，互不影响
- [x] 「关闭连接」仅断开该库，列表条目保留
- [x] 可删除连接配置；已打开时需先关闭或一并关闭
- [x] 重启应用后连接列表仍在
- [x] 无效路径 / 锁定 / 只读写拦截等行为正确

### Epic 2: Schema 探索

```
作为开发者，
我希望在侧边栏看到所有表和视图，
以便了解数据库结构。
```

**验收标准:**
- [x] 每个**已打开**连接下，侧边栏按字母序列出 `table` 与 `view`
- [x] 点击表名，主区展示该连接下的列定义 / 数据

### Epic 3: 数据浏览

```
作为开发者，
我希望分页浏览表数据并排序，
以便检查记录内容而无需写 SQL。
```

**验收标准:**
- [x] 默认每页 50 行，可选 25 / 50 / 100 / 200
- [x] 支持点击列头排序（升序/降序切换）
- [x] 显示当前页码与总页数（或「共 N 行」）
- [x] BLOB 类型显示为 `[BLOB N bytes]`，不渲染二进制

### Epic 4: SQL 工作台

```
作为开发者，
我希望在 SQL 编辑器中执行查询并看到结果，
以便灵活探索数据。
```

**验收标准:**
- [x] 支持多行 SQL 输入，Monaco 编辑器 + 语法高亮（P1）
- [x] 执行 SELECT 返回表格化结果集 + 行数 + 耗时
- [x] 执行写操作前弹出确认对话框，展示影响行数
- [x] SQL 语法错误时，展示数据库返回的错误信息
- [x] 支持 `Cmd/Ctrl + Enter` 快捷键执行

## 5. 竞品参考（摘要）

| 产品 | 优势 | Data Nexus 差异化 |
|------|------|---------------------|
| DB Browser for SQLite | SQLite 功能最全、Spreadsheet 编辑 | 现代 Web UI、单二进制、API 原生、多库路线 |
| Beekeeper Studio | 精美 UI、自动补全、多 Tab | 更轻量、开源全栈、可嵌入、无 Electron |
| TablePlus | Native 性能、极简 | 开源、Web 可集成、API-First |
| DBeaver | 100+ 数据库、ER 图 | 聚焦开发者日常、秒开、不做 heavyweight |
| Datasette | Filter/Facet/FTS、JSON API | 更强 SQL 工作台 + 同样 API 理念 + 多库扩展 |
| Tabulita | Go 单二进制、JSON API | **Wails 桌面 + 现代 UI**、原生对话框、多库路线 |
| sqlite-web | 极简 Python Web、导入导出 | Go 部署更简单、TypeScript 前端、架构可扩展 |
| DuckDB UI | 列画像、Notebook、Instant SQL | 借鉴探索 UX，但聚焦 SQLite + 多库平台 |
| Sqlime | 零服务端 WASM | 原生桌面 + 本地文件对话框 + 多库路线 |

## 6. 风险与假设

| 类型 | 描述 | 缓解措施 |
|------|------|----------|
| 假设 | 用户在本机运行，可访问文件系统 | MVP 不做远程文件；后续可考虑文件上传 |
| 风险 | SQLite 写操作误删数据 | 写操作二次确认 + 只读连接模式（P0） |
| 风险 | 大表/大结果集内存溢出 | 强制分页 + 结果集行数上限（如 10,000） |
| 风险 | 多数据库抽象过度设计 | MVP 仅实现 SQLite Driver，接口预留但不提前实现 |

## 7. 术语表

| 术语 | 定义 |
|------|------|
| Connection | 一次到数据库实例的活跃会话 |
| Schema | 数据库内表、视图、索引等结构元信息 |
| Driver | 后端适配特定数据库类型的连接与元数据查询模块 |
| Workspace | 前端整体布局区域（侧边栏 + 主内容区） |

## 8. 决策记录（原开放问题，均已确认）

- [x] MVP 是否需要「只读连接」模式？→ **连接时可勾选，默认读写**
- [x] 文件选择方式？→ **MVP 原生文件对话框（Wails）+ 可选路径输入**
- [x] 是否需要 i18n？→ **需要**；MVP 接入 `react-i18next`，默认语言 **zh-CN**，文案全部走 i18n key，并预留 **en** 语言包
- [x] v0.3 是否做 Filter→SQL？→ **做**；v0.3 按 [phase-v0.3-exploration.md](../implementation/phase-v0.3-exploration.md) 交付
- [x] 连接信息是否持久化？→ **MVP 需要**；v0.5 起 `catalog.db` 常驻主界面列表（不迁移 json）
- [x] 多连接？→ **MVP 即支持**；类 Navicat，同时打开多个 SQLite；启动直接进入主界面
